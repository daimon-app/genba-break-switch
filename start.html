切り替えスイッチは、休憩を始め、30秒から整え、休憩後の「次の一手」を一つだけ見て作業へ戻るための、モバイル優先の無料公開ベータです。

休憩の後が、いちばん散る

全部を片づけなくていい。
まず、戻る場所を一つ。

現場では、休憩を取ることと、休憩から戻ることは別の行動です。切り替えスイッチは、休憩の長さと小さな行動を表示し、戻る作業を一言で残します。仕事を管理するアプリではなく、再始動のきっかけを手元に置くための道具です。

01 / START

休憩を決める

通常・暑い日・重作業・時間休憩から、自分に合う休憩時間を選びます。

02 / RESET

30秒から整える

目、肩、呼吸、水分などの短いチェックを見ながら、必要なだけ立ち止まります。

03 / RETURN

次の一手を見る

戻ったら最初にやる作業を一つだけ入力。休憩の終わりに、もう一度表示します。

現行ベータで使えること

短く、迷わせない。

マイクロリセット

30秒、1分、3分、5分。作業の切れ目に合わせて、短い時間から始められます。

瞑想・整えタイマー

30秒の「断ち切り」から、1分以上の整え時間まで。自然音は任意で切り替えられます。

休憩後の一手

「ボードを1枚貼る」など、最初に着手する作業を入力して、終盤と完了時に見直せます。

端末内の記録

利用履歴と簡単な集計を、このブラウザ・この端末の中で確認できます。

NOT AN ALARM. A RETURN CUE.

これは、標準アラームの代わりではありません。

時間を確実に知る必要がある休憩には、端末標準のタイマー／アラームを併用してください。切り替えスイッチが担うのは、休憩の開始、短い整え、次の一手の確認です。

対応端末での画面消灯防止について

タイマー中は、対応端末で画面消灯を抑制するよう試みます。ただし、端末設定、低電力状態、画面の非表示化などにより解除または利用できない場合があります。

大切な注意

安全管理や体調判断は、代わりません。

暑い日モードは、固定の休憩提案です。

熱中症の予防・診断・安全確保・法令遵守を保証する機能ではありません。暑さ指数、作業強度、服装、体調、現場責任者の指示、公式の安全衛生情報に基づいて休憩・作業中止等を判断してください。
