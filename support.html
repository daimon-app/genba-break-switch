PUBLIC FEEDBACK

GitHub Issuesで送る

不具合報告・改善要望は、公開のGitHub Issuesを利用します。利用端末、OS、ブラウザ、再現手順、期待した動作、実際の動作を、分かる範囲で記載してください。

公開フィードバックを開く

BEFORE YOU POST

投稿は公開されます

GitHub Issuesの内容は第三者から閲覧できる場合があります。氏名、電話番号、メールアドレス、住所、現場名、顧客情報、写真、位置情報、作業予定、パスワード、決済情報その他の個人情報・機密情報は投稿しないでください。

よい報告の例

項目例
端末・OS・ブラウザAndroidのChrome／iPhoneのSafariなど。分かる範囲でOSバージョンも記載。
行った操作「30秒リセットを押した後、画面を消してから戻った」など。
期待したこと「戻ったときに残り時間を見たかった」など。
実際に起きたこと「時間表示が変わらなかった」「音が鳴らなかった」など。

画面のスクリーンショットを共有する場合も、現場名、氏名、連絡先、位置情報、写真に映り込んだ個人情報等を確認してください。

現在受け付けないもの

  • 個別の体調相談、医療相談、安全判断、労務判断
  • 緊急の連絡、事故・危険発生時の連絡
  • 有償商品の購入、返金、決済に関する問い合わせ（現在は有償販売を行っていません）
  • 個人情報・機密情報を含むサポート依頼
緊急時は本サービスを使わないでください。

体調不良、事故、危険の兆候がある場合は、現場のルール、責任者の指示、緊急連絡手段、必要に応じた公的な緊急サービスを優先してください。

正式な問い合わせ窓口について

販売者情報、個別対応方針、個人情報の取扱いが確定するまで、非公開の問い合わせフォームやメール窓口は設置していません。有償販売または個別サポートを開始する場合は、連絡先、対応時間、個人情報取扱いを明示した窓口を開設します。
