INSTALL GUIDE

手元に置く。

ホーム画面への追加は任意です。表示される名称、手順、使える機能は、端末・OS・ブラウザ・設定により異なります。

ANDROID

Androidの場合

  1. 対応ブラウザで切り替えスイッチを開きます。
  2. ブラウザのメニューから「アプリをインストール」または「ホーム画面に追加」を探します。
  3. 画面の案内に従って追加します。

インストール候補の表示には、ブラウザ側の条件や利用状況が影響します。表示されない場合は、ブラウザでそのまま利用してください。

IPHONE / IPAD

iPhone・iPadの場合

  1. Safariで切り替えスイッチを開きます。
  2. 共有ボタンをタップします。
  3. メニューから「ホーム画面に追加」を選び、追加します。

iPhone・iPadでは、利用するブラウザや端末設定によって追加方法や挙動が変わることがあります。Safariでの操作を推奨します。

追加後にできること

ホーム画面から起動すると、ブラウザのタブ一覧を探さずに切り替えスイッチを開けます。初回読み込みと更新が完了した後は、基本機能をオフラインで開けるよう設計しています。

終了通知について

ホーム画面に追加しても、現行ベータはOSアラームやOSプッシュ通知を提供しません。時間を確実に知る必要がある場合は、端末標準のタイマー／アラームを併用してください。

うまく追加できないとき

状況試すこと
追加メニューが見つからない別の対応ブラウザで開く、またはブラウザのメニュー名称を確認してください。
「インストール」が表示されないページを一度操作してから少し待つ、HTTPS接続を確認する、ブラウザを更新するなどを試してください。
オフラインで開かない一度オンラインでページを開き直し、更新が完了した後に再度試してください。
終了音が鳴らない／画面が消える端末設定・音量・低電力状態・ブラウザ制限を確認し、必要に応じて端末標準タイマーを併用してください。

個人情報を含まない不具合報告は、サポートから送れます。
