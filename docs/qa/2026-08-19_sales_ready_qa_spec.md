# 切り替えスイッチ — SALES READY QA仕様

> **版:** v0.1
> **作成日:** 2026-08-19 JST
> **対象:** `main` の無料公開ベータPWA、案内LP、FAQ、利用規約、プライバシー、販売案内、サポート導線
> **判定基準:** 実コード、ローカル実画面、公開後のGitHub Pages実画面、リンク、PWA設定、販売表現を照合する。

## QA対象と優先度

| ID | 区分 | 検証内容 | 方法 | 合格基準 |
| --- | --- | --- | --- | --- |
| Q-01 | 配布 | HTML・CSS・manifest・Service Workerの構文と参照整合 | 静的検査 | 必須ファイルが存在し、manifest・Service Workerの参照先が存在する。 |
| Q-02 | ブランド | title、ホーム表示、manifest、Apple Web App title | 静的検査＋実画面 | 外部表示名称が「切り替えスイッチ」に整合する。 |
| Q-03 | LP | `start.html` の表示、無料公開ベータの明示、PWAへの導線 | 実画面＋リンク検査 | LPが開き、「無料で試す」でPWAへ到達する。購入・決済は設置されない。 |
| Q-04 | 法務導線 | 利用規約、プライバシー、販売案内、サポートが相互に到達可能 | リンク検査 | 全ページが200で開き、フッター等から到達できる。 |
| Q-05 | 表現 | OS通知、OSアラーム、画面消灯防止、熱中症、安全、医療効果 | テキスト監査 | 未実装機能・結果を約束せず、制約・併用・安全上の注意を明示する。 |
| Q-06 | PWA | manifestとService Worker、cache assets | 静的検査＋ブラウザ検査 | 主要ページ・音源・アイコンをキャッシュ対象に含み、Service Workerが登録される。 |
| Q-07 | 操作 | ホーム→マイクロリセット→開始、ホーム→LP、ホーム→FAQ | ブラウザ手動検査 | 主要導線が反応し、画面遷移に行き止まりがない。 |
| Q-08 | タイマー | 30秒／1分セッション、一時停止、終了処理、休憩の次の一手 | ブラウザ手動検査 | 表示・一時停止・復帰・終了画面が仕様通り。終了音の可聴性は実機別に限界を記録する。 |
| Q-09 | 中断 | 非表示→復帰時の残時間再計算、Wake Lockの制約表示 | ブラウザ手動検査＋コード照合 | 復帰後の残時間再計算を確認。OSバックグラウンド保証は判定対象外として明示する。 |
| Q-10 | モバイルUX | 小さな画面の可読性、タップ対象、横スクロール、フォーカス | ブラウザ実画面 | 主要ボタンが視認・操作でき、致命的な横スクロールがない。iOS/Android実機は別途実機確認を必要とする。 |
| Q-11 | 公開 | GitHub Pagesにpush後、`start.html`・PWA本体・ポリシー頁が到達可能 | 公開URLブラウザ検査 | 主要ページが公開URLで開く。 |
| Q-12 | 販売境界 | 購入・決済・フォーム・特商法表記の状態 | 目視＋テキスト検査 | 有償販売を開始していないことを表示し、購入導線・決済フォームが存在しない。 |

## FAILの分類

| 分類 | 定義 | 対応 |
| --- | --- | --- |
| BLOCKER | 購入誤認、未実装機能の約束、リンク切れ、公開不能、個人情報・決済の危険な入力導線 | 修正後に再QA。無料公開ベータでもSALES READY不可。 |
| TECH_FIX_REQUIRED | コード、キャッシュ、名称整合、導線、端末互換に関する修正必要事項 | 修正優先度を付け、修正と再QAを記録する。 |
| APPROVAL_REQUIRED | 販売者情報、価格、決済、返金、正式商品名、投稿等の本人判断が必要な事項 | 実装と判定を分離し、本人承認まで有効化しない。 |
| LIMITATION | OS・ブラウザ・ホスティングの仕様上、製品で保証できない事項 | FAQ・LP・規約に明示し、販売文言で約束しない。 |

## 実機QAの境界

この環境で検証できないiOS／Android実機上のインストール手順、バックグラウンド音、低電力時のWake Lock、通知権限、物理端末上の視認性は、実機確認が必要である。これらは、無料公開ベータの公開前に可能な限り確認し、有償販売に進む前には必須で再検証する。
