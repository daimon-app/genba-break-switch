# 切り替えスイッチ — CM Production Package

Status: **PRODUCTION READY / NOT PUBLISHED**

共通CTAは「無料公開ベータを試す」。OS通知、安全、健康効果、作業効率向上を保証しない。第三者素材は使わず、実アプリ画面と権利確認済みの現場B-rollのみを使用する。

## 6秒

- Concept: 休憩後の迷いを一つに絞る。
- Script / narration: 「休憩のあと、次の一手だけ。」
- Shot list: 0–2秒 Problem文字、2–5秒「次の一手」画面、5–6秒ロゴ＋CTA。
- Subtitle / on-screen: 「休憩のあと、次の一手だけ。」「切り替えスイッチ｜無料β」
- CTA: 「ブラウザで試す」
- Thumbnail: 黒背景、金文字「次の一手だけ。」、実画面。
- Platform: X / Instagram Reels / Threads / TikTok / YouTube Shorts向け縦9:16。X用は1:1も書き出す。

## 15秒

- Concept: 休憩→30秒リセット→再始動。
- Script: 「休憩したのに、戻る一手が決まらない。30秒だけ整えて、次にやることを一つ見る。切り替えスイッチ、無料公開ベータ。」
- Shot list: 0–3秒 Problem、3–8秒30秒タイマー、8–12秒次の一手、12–15秒ロゴ＋CTA。
- Subtitle: narration全文。無音視聴でも理解できるサイズにする。
- B-roll: 手袋を置く、深呼吸、スマートフォンを見る。危険作業中の操作は撮らない。
- CTA: 「無料で試して、使いにくさを教えてください」
- Title: 「休憩から戻る一手を、30秒で。」
- Caption: 「現場の短い休憩と再始動のための無料公開ベータPWA。OSアラームや安全管理の代替ではありません。」

## 30秒

- Concept: 複数の現場休憩を一つの短い体験にする。
- Script: 「休憩は取れた。でも、仕事へ戻る最初の一手が曖昧なまま。切り替えスイッチは、30秒からの短いリセット、休憩タイマー、そして次の一手の確認を一つにしたPWAです。アプリの追加購入は不要。ブラウザから無料公開ベータを試して、現場での使いにくさを教えてください。」
- Shot list: 0–5秒状況、5–12秒モード選択、12–19秒タイマー、19–24秒次の一手、24–27秒ホーム画面追加、27–30秒制約＋CTA。
- On-screen limitation: 「画面表示中のタイマー／OSアラームの代替ではありません」
- CTA: 「無料βを試す」「公開フィードバック」
- Thumbnail: 実画面＋「休憩から、次の一手へ。」
- Platform adaptation: YouTube/Xは16:9、Reels/TikTok/Shortsは9:16。重要文字を中央safe areaへ置く。
