## PWA本体への変更

| パス | 施工内容 | 理由 |
| --- | --- | --- |
| `index.html` | タイトルとApple Web App title、ホーム表示名を「切り替えスイッチ」に整合。案内LPとFAQへのリンクを追加。 | 旧称／新称の表示不整合を縮小し、アプリから制約・ポリシーへ到達できるようにする。 |
| `manifest.json` | `name`、`short_name`、説明を販売名称・現行提供価値へ整合。 | インストール後の名称と説明を整合する。 |
| `service-worker.js` | キャッシュ名を `kirikae-v10` へ更新し、案内・ポリシー・サポートのHTMLと共通CSSをキャッシュ対象へ追加。HTMLはnetwork-firstで取得する。 | 更新配信を確実にし、既存PWA利用者へ安全情報・ポリシー・商品名更新を届け、案内ページも基本オフライン利用の対象に含める。 |

## 表現に関する施工ルール

LP・FAQ・利用規約・SNS案では、次の機能・結果を約束していない。

- OSプッシュ通知、OSアラーム、バックグラウンド終了通知、終了時の確実な音声
- 画面消灯防止の恒常的な成功
- 熱中症の予防・診断、安全確保、法令遵守、勤怠・工程・危険予知の代替
- 集中力・疲労・ストレス等に関する結果の保証
- 有償販売、決済、サブスクリプション、返金保証、個別サポート

## 未実装・本人承認待ち

| 項目 | 未実装理由 | 有効化・実装の条件 |
| --- | --- | --- |
| 決済ボタン・購入導線 | GitHub Pagesの商取引制約、販売者・価格・返金・決済未確定 | 商取引可能な基盤に移行し、特商法表記・決済前表示・本人承認を完了する。 |
| 問い合わせフォーム・メール窓口 | 販売者・個人情報取扱い・対応方針未確定 | 正式な連絡先、対応時間、Privacyを確定する。 |
| 販売者情報 | 実情報未提供 | 本人が正確な法定表示情報を承認する。 |
| アファメーションのカスタム機能 | 現行コードに存在しない | 体験仕様・保存方法・Privacy・QAを設計後に実装する。 |
| OS Push・バックグラウンド通知 | サーバー、Push購読、Service Worker通知処理、権限UXがない | 専用設計・インフラ・対応端末QAを完了する。 |
