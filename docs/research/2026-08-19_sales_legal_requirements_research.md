# 切り替えスイッチ — 販売表示・個人情報取扱い調査

> **調査日:** 2026-08-19 JST
>
> **対象:** 日本国内向けのデジタル商品／PWA販売を想定したLP、外部決済、問い合わせ、返金案内
>
> **注意:** 本資料は一次情報を整理した販売施工用の作業記録であり、正式な法律意見ではない。販売開始前に、実際の販売形態、決済、法人・個人事業者の属性、広告表現を専門家に確認する。

## 結論

有償でPWA、デジタルコンテンツ、導入支援その他の役務をオンラインで販売する場合、通信販売に関する表示と申込段階の表示を整備する必要がある。消費者庁は、通信販売を行う事業者に対して、事業者の氏名（名称）、住所、電話番号等の広告表示、誇大広告の禁止、特定申込みを受ける際の表示、顧客の意に反する申込みをさせようとする行為の禁止等を案内している。[1]

現時点では販売者の正式名称、住所、電話番号／公開代替手段、メールアドレス、法人代表者（該当する場合）、決済事業者、価格、提供時期、返金条件が未提供である。したがって、**特定商取引法に基づく表記を実名・実態で確定して公開することはできない。** 虚偽の販売者情報や仮の返金条件を公開せず、これを本人承認待ちの販売ブロッカーとして扱う。

## 一次情報で確認した要件

| 論点 | 一次情報で確認した事項 | 本施工への適用 |
| --- | --- | --- |
| 通信販売該当性 | インターネット上で申込みを受けて行う販売は通信販売に該当し得る。個人でも要件を満たせば「販売業者（役務提供事業者）」に該当し得る。[1] | 個人販売を含め、販売開始前に特商法表記を整備する。 |
| 広告表示 | 消費者庁は、事業者の氏名（名称）、住所、電話番号等を表示すべきと案内する。[1] | 販売者情報未確定のため公開不能。氏名等を提供後、LPと決済前画面の双方で整合させる。 |
| 誇大広告 | 通信販売では誇大広告等が禁止され、他法令でも虚偽・誇大な広告が禁止される。[1] | 「熱中症を防ぐ」「安全を保証」「確実に鳴る」「集中力を回復する」等の結果保証を採用しない。 |
| 最終確認画面 | 消費者庁は、通信販売の申込み段階の表示に関するガイドラインを公開している。[2] | 外部決済を使う場合でも、商品・価格・支払・提供・解約／返金の重要情報が決済前に明瞭か確認する。 |
| 返品・返金 | 返品・返金条件は、提供物・提供時期・利用開始後の扱いと一体で設定する必要がある。 | デジタル提供開始後の返金可否を含め、本人が明確に決める。条件未確定のまま「返金保証」と表示しない。 |
| 個人情報 | 個人情報保護委員会は、個人情報保護法等、ガイドライン、Q&A、漏えい時の対応等を公開している。[3] | 現行PWAが扱う端末内記録と、LPフォーム・外部決済・アクセス解析で扱う情報を区別して開示する。 |

## 現行実装に対するプライバシー判定

現行コードを確認した範囲では、休憩履歴、音設定、次の一手はブラウザの `localStorage` に保存され、アカウント作成、サーバー送信、外部分析SDK、広告SDK、位置情報、連絡先、決済情報の収集は確認できない。これは**コード確認時点の現行PWA本体**に限る。

販売LPに問い合わせフォーム、メール配信、アクセス解析、決済リンク、埋込動画、SNSピクセル等を追加する場合は、それぞれが新たなデータ取扱いとなる。プライバシーポリシーには、実際に使う事業者名、取得情報、目的、保存先、外部委託・第三者提供、開示等の請求窓口、改定手順を追記して再監査する。

## 販売開始を妨げる情報欠損

| 必須確定事項 | 現在の状態 | 販売開始への影響 |
| --- | --- | --- |
| 販売者の正式名称 | 未提供 | 特商法表記を確定できない。 |
| 住所 | 未提供 | 特商法表記を確定できない。 |
| 電話番号または適法な表示方法の判断 | 未提供 | 表示方法の確定が必要。 |
| 問い合わせメールアドレス／対応時間 | 未提供 | 問い合わせ導線を公開できない。 |
| 販売形態 | 未確定 | PWAアクセス販売、導入支援、買切り、サブスク等で表記・返金・決済が変わる。 |
| 決済事業者・商品URL | 未確定 | 決済リンク、最終確認画面、購入完了後導線を実装できない。 |
| 価格・消費税・継続課金の有無 | 未確定 | 広告・決済表示を確定できない。 |
| 提供時期 | 未確定 | デジタル利用開始時期・導入支援実施時期を確定できない。 |
| 返金条件 | 未確定 | FAQ・特商法表記・決済表示を確定できない。 |

## 販売文言のガードレール

| 禁止する表現 | 理由 | 代替表現 |
| --- | --- | --- |
| 「熱中症を防ぐ」 | 現行機能は安全状態を測定・診断・保証しない。 | 「休憩の開始と次の一手の確認を支える」 |
| 「現場の安全を保証」 | 安全装置・緊急連絡・作業中止判断機能を持たない。 | 「安全管理の代替ではありません」 |
| 「時間になれば必ず通知・アラーム」 | 現行PWAにはOS通知・OSアラーム・Pushがない。 | 「画面表示中のタイマーと終了音。必要に応じて標準タイマーを併用」 |
| 「画面が消えない」 | Wake Lockは端末設定等で解除され得る。 | 「対応端末では画面消灯を抑制するよう試みます」 |
| 「集中力を回復する」「ストレスを治す」 | 効果を保証・医療的に示す根拠と機能がない。 | 「切り替えのための短い時間をつくる」 |
